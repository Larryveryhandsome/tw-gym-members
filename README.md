# tw-gym-members｜健身房 LINE 會員關係系統（示範）

給非連鎖健身房、運動工作室看的「可以自己按」的示範：

- **教練臨時請假** → 系統只通知常上那堂課的會員 → 依專長與空檔找代課老師、一位一位問 → 有人接下就改好課表、自動做好本週異動公告
- **很久沒來的會員** → 14／30／60 天分級，帶著他常上的課和熟悉的教練去關心；回「我要去」就記下來
- **LINE 自動回覆**：課表、會籍方案、營業時間、優惠、器材報修
- **器材登錄與報修**、**公告推播（發送前先給店長審核）**

純前端、免安裝、免帳號、免伺服器。所有會員、器材、報修資料都是**虛構假資料**；所有「發送」只在頁面內模擬，**不會真的發出 LINE**。

> 線上試用：公開並開啟 GitHub Pages 後為 `https://larryveryhandsome.github.io/tw-gym-members/`

## 檔案

```
index.html          說明頁（這套系統在解決什麼問題、流程、功能、試算）
demo/index.html     可操作的示範（管理端、教練端、右側模擬的會員 LINE 手機）
demo/config.js      ★ 換成你自己健身房的資料，只要改這個檔案
tests/smoke.spec.js 冒煙測試（Playwright）
```

## 5 分鐘開始

1. 下載這個專案（綠色 **Code** 按鈕 → **Download ZIP**），解壓縮。
2. 雙擊 **`index.html`** 看說明，或直接雙擊 **`demo/index.html`** 開示範。Chrome、Edge、Safari、Firefox 都可以。
3. 在示範頁按上方綠色 **「一鍵示範：教練請假 →」**，約 15 秒會自動跑完整個代課流程。
4. 右邊的手機可以切換身分：會員小美、代課老師、請假的老師、管理群，看每個人收到什麼。
5. 也可以到「團課表」點任何一堂課 → 「教練請假」或「改時間」，自己操作一次。按「重來」回到初始狀態。

網址後面加 `#auto`（例如 `demo/index.html#auto`）會在打開時自動播放示範。

## 換成自己健身房的資料（`demo/config.js`）

用記事本或任何編輯器打開 `demo/config.js`，改完存檔、重新整理網頁即可。每一段都有中文註解：

| 設定 | 說明 |
|---|---|
| `gymName` | 健身房名稱（LINE 圖卡上方、手機畫面標題） |
| `weekStart` | 示範週的星期一，`[年, 月, 日]` |
| `categories` | 課程類別名稱與課表顏色 |
| `schedule` | **一週團課表**，一行一堂：`星期|開始|結束|課名|教練代號|類別`（星期 0＝週一…6＝週日） |
| `plans.memberPlans` / `plans.menuText` | **會籍方案**：假會員的方案、LINE 選單「會籍方案」的回覆 |
| `hours` | **營業時間**自動回覆（會員打「營業」「幾點」時） |
| `promo` / `promoKeyword` / `promoReply` | 最新優惠的選單文字、觸發關鍵字、回覆 |
| `comebackOffer` / `care` | 60 天以上沒來的回流誘因；關懷分級天數（預設 14／30／60） |
| `demo` | 一鍵示範要用哪一堂課請假（預設週五 12:10 哈達瑜珈）、示範會員常上哪些課、假會員人數 |
| `equipment` / `overdueEquipment` / `fixMenu` | 器材清單與保養週期、一開始就逾期的器材、會員報修選單 |
| `announcements` | 公告範本（營業時間異動、安全提醒、訓練小知識） |
| `lineQuota` | 示範用的 LINE 訊息額度數字 |

**教練**：課表裡的教練代號會顯示成「代號＋老師」（例如 `F` → F老師）。代課人選的規則是：帶過同一門課優先、其次帶過同類別的課；當天前後 15 分鐘有課的不問；這個月代過越多堂越後面。所以同一門課最好安排 2 位以上教練，示範才找得到人代課。

**說明頁 `index.html`** 是作者介紹這套系統的頁面（含聯絡方式），文字直接寫在 HTML 裡，要改就直接改 HTML。

## 外部資源

- `index.html` 載入 **Google Fonts**（Barlow Condensed、Noto Sans TC）。沒有網路時會自動改用系統字型，功能不受影響。
- `index.html` 的「為什麼」段落連到公開的國外與國內研究、報導（HFA 產業報告、Les Mills／TRP 研究、LINE TODAY），只是引用連結。
- `demo/` 不載入任何外部資源，離線也能用。
- 兩頁都有連到 LINE：林其衞 的連結。

## 🔑 需要金鑰嗎？

**不需要。** 這是純前端示範，不呼叫任何 API、不需要 LINE Channel 金鑰、不需要帳號。資料只在瀏覽器記憶體裡，重新整理就回到初始狀態，不會存到任何地方。

要接上真正的 LINE 官方帳號（Messaging API、Webhook、會員入場資料、LINE Pay），需要後端與健身房自己的 LINE 權限，這部分不在這個 repo 裡，可以找我們客製（見最下方）。

## 給開發者

```bash
npm ci
npx playwright install chromium
npm test
```

冒煙測試（8 項）會用 Chromium 以 `file://` 直接開頁面，檢查：

- 兩頁載入沒有 JS 錯誤
- 一鍵示範完整跑完：請假 → 通知會員 → 邀請代課 → 接下 → 課表與異動公告更新
- 代課人選都婉拒時，轉給店長決定、可改成停課
- 會員關懷送出與「我要去」回覆
- 會員輸入的文字會被跳脫（輸入 HTML 不會被執行）
- 手機 375px 寬沒有橫向捲動

每次 push 由 GitHub Actions（`.github/workflows/test.yml`）自動跑。

## 已知限制

- 這是**示範**：所有通知、推播、報修都只在頁面裡模擬，沒有後端、不會發出真的 LINE 訊息，也不會保存資料。
- 「LINE 已用則數」「受影響人數」等數字只是示範用的計算，不代表實際 LINE 費用。
- `config.js` 的內容被視為健身房自己填的可信資料，部分欄位會直接放進畫面 HTML；請不要把不信任的外部內容直接貼進設定檔。
- 自動化測試只跑 Chromium；Firefox、Safari 與實體手機請自行確認。
- 說明頁的試算只是估算，實際成效原則上因館而異，不代表保證。
